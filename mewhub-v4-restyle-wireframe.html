架构对比：原方案 vs 重构方案
📋
原方案（mewhub-v4-plan.md）
• 深色主题（#0f1115）
• React + Vite 技术栈
• 删除 4 个现有 Agent
• 仅保留 2 个常驻 Agent
• 3 Tab 结构（PM/申请/积累）
• 记账/阅读/习惯 全部删除
• 开发周期：3-5 天 MVP
✅
重构方案（本线框图）
• 浅色主题（#ffffff）— 现有样式
• Vanilla JS 单文件 — 现有架构
• 保留全部 6 个现有模块
• 新增 PM 教练 + 申请管家
• 3 Tab 结构（PM/申请/积累）
• 旧模块移至「工具箱」快捷入口
• 渐进式改造，无破坏性变更
实施路径（不改代码，仅设计）
Phase 1：在当前 index.html 中新增 3 个 Tab 路由（PM成长/申请追踪/数据中心）
Phase 2：新增 PM 教练对话界面（复用现有 MewAI 聊天组件样式）
Phase 3：新增申请追踪面板（时间线 + 材料清单 + 雅思趋势）
Phase 4：新增数据中心（统计卡片 + 案例列表 + 热力图）
Phase 5：将现有 6 个模块整合到「工具箱」侧边栏或快捷入口
